# Domain docs

Estrutura de contexto único:
- CONTEXT.md na raiz: vocabulário e contexto do domínio.
- docs/adr/: registros de decisões arquiteturais.

Antes de explorar o código, ler CONTEXT.md e os ADRs relevantes.
Se ainda não existirem, continuar normalmente.
Criá-los quando termos ou decisões forem efetivamente definidos.

Usar o vocabulário de CONTEXT.md nas tarefas, propostas e testes.
Apontar explicitamente qualquer conflito com um ADR existente.
