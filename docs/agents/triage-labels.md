# Triage labels

- needs-triage: precisa de avaliação.
- needs-info: aguarda informações de quem abriu a issue.
- ready-for-agent: especificada e pronta para implementação pela IA.
- ready-for-human: exige implementação humana.
- wontfix: não será implementada.

Cada papel usa a etiqueta de mesmo nome no GitHub.
